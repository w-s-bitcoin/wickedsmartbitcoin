## Hover tooltips

Historical chart inspection and supply-bar/activity-badge tooltips use the
shared `wsb-tooltip` shell and escaped labeled rows. Series colors identify small
swatches; text stays neutral. The methodology and missing-detail notices remain
visible as wrapping notes. Explanatory control help uses the shared help size.

For review, switch `#scriptPanelModeToggle` between bars and historical mode,
hover `.historical-svg`, supply segments, and activity badges, and open
`#snapshotReportButton` to inspect help within the secondary report panel.
Tooltip bounds still follow that report panel where applicable. Check both
themes and narrow widths. Further dashboard-standard adoption is separate:
historical inspection retains its existing mouse interaction and mobile tooltip
suppression/tap behavior.
